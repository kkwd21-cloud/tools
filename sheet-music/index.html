(0이면 원곡만 나와요)

"원곡 들으며 악보 따라가기"를 누르면 원곡만 나오고, 악보의 보라색 선과 가사가 노래를 따라가요. 악보가 맞는지 확인하고 싶을 때만 "악보 소리" 슬라이더를 올려 원곡과 같이 들어 보세요. (키를 바꿔 둔 상태에서는 원래 키로 틀어요.)

이 도구는 이렇게 써요

  1. 위 상자에 노래 파일(MP3·WAV)을 끌어다 놓아요.
  2. 키, BPM, 코드 진행, 멜로디 악보가 나올 때까지 잠깐 기다려요. (처음엔 분석 도구를 내려받느라 조금 더 걸려요.)
  3. 틀린 코드는 눌러서 고치고, 악보와 원곡을 번갈아 들어 보세요.
  4. MIDI로 저장하거나, 키·BPM을 수노 스타일 문구로 복사해 새 곡을 만들 때 쓰세요.

자주 묻는 질문

MP3 파일로 악보를 만들 수 있나요?

네. MP3, WAV, M4A 같은 노래 파일에서 키, BPM, 코드 진행, 멜로디 악보를 자동으로 만들어 줘요. 다만 사람이 직접 채보한 악보만큼 정확하지는 않아서 틀린 코드를 고칠 수 있게 했어요.

파일이 서버에 올라가나요?

아니요. 모든 분석은 내 기기의 브라우저 안에서만 이루어지고 파일은 어디로도 보내지 않아요.

악보가 정확하지 않아요.

반주가 섞인 곡은 멜로디가 틀리기 쉬워요. 보컬만 따로 분리한 파일을 넣고 “보컬/멜로디만 있는 파일”을 고르면 훨씬 정확해져요. 코드는 반주가 섞여 있어도 꽤 잘 맞아요.

코드 악보나 MIDI로 저장할 수 있나요?

코드 진행은 복사할 수 있고, 멜로디와 코드는 MIDI 파일로 저장할 수 있어요.

수노(Suno)로 만든 노래도 되나요?

네. 수노에서 받은 MP3·WAV 파일을 그대로 넣으면 돼요. 키와 BPM을 수노 스타일 문구로 바로 복사할 수 있어서, 마음에 든 곡과 비슷한 곡을 다시 만들 때 편해요.

Dusk Soul 무료 툴킷 · 곡 느낌 사전 — 분석에는 오픈소스 Basic Pitch(Apache-2.0)와 abcjs(MIT)를 사용했어요. 결과는 참고용 근사치예요.
