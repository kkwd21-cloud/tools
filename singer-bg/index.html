가상 가수 배경 영상 만들기

내 노래를 올리면 가상 가수가 노래에 맞춰 입을 움직이며 부르는 영상이 나와요. 만든 영상은 뮤직 영상의 배경으로 쓸 수 있어요.

노래 파일을 올리면 미리 볼 수 있어요
1. 노래 파일
2. 표현 방식
3. 가수 고르기
4. 배경 고르기
5. 가수 위치
영상 만들기는 노래 길이만큼 걸려요. 창을 닫지 마세요.

어떻게 쓰나요?

노래를 올리고 가수와 배경을 고른 뒤 "영상 만들기"를 누르세요. 노래가 끝나면 영상 파일을 저장할 수 있어요. 저장한 영상은 뮤직캔버스 같은 편집 프로그램에서 배경 영상으로 넣고, 원래 노래 파일을 음악으로 쓰면 돼요.

실제 가수 얼굴이나 목소리와 같은가요?

아니에요. 직접 그린 가상 인물이라 실제 가수와 관련이 없어요. 입 모양은 노래의 소리 크기와 음색에 맞춰 움직이는 만화풍 표현이라, 가사 발음까지 정확히 맞추지는 않아요.

파일이 서버에 올라가나요?

아니요. 모든 처리가 내 브라우저 안에서 이뤄지고 어디로도 전송되지 않아요.
