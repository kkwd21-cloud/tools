    When to use it

    • A last check before you generate

      Suno spends credits on every run. A quick check before you paste can cut down wasted runs.

    • When results keep coming out odd

      Clashing words in the style or a misspelled lyric tag are common causes. Find them with the checker first.

    • When using someone else's prompt

      Check whether a prompt copied from the web has artist names or too many keywords.

    Common mistakes

    • Naming an artist

      Suno often rejects or ignores styles that name real artists. Describe the voice, genre and mood instead.

    • Too many keywords

      Past about 10, the later words tend to fade. Try 4 to 7.

    • Mixing calm and intense words

      Use one for the whole song and split the rest with section tags like [Verse: soft] and [Chorus: powerful].

    • Misspelled tags

      A tag like [Choruss] may be read as plain words. Spell it exactly.

    • A different chorus every time

      A chorus sticks when it repeats exactly.

    • Putting what you want removed in the style

      Writing no drums can make it count the other way. Put it in the Exclude Styles box.

    Questions

    Is this checker free?

    Yes. It is free, needs no sign-up, and all checking happens in your browser.

    Is my text uploaded to a server?

    No. This site is a static page with no server, so your text is never sent anywhere.

    Does an AI do the checking?

    No. It uses fixed rules such as character count, the number of comma-separated keywords, repeated words and tag spelling. That makes it fast and consistent.

    Is the result guaranteed to be right?

    No. How Suno reads a prompt changes by version. Treat the result as a guide, because Suno may still react differently after you fix things.

    What are the character limits?

    They depend on the Suno model. This tool lets you choose between a newer model (1,000 style and 5,000 lyric characters) and an older one (200 style and 3,000 lyric characters). Go by the limit you see in Suno.

    Does it save Suno credits?

    It only helps you avoid mistakes before you generate. It does not save credits by itself.

    Do I have to write in English?

    English keywords tend to work better in the style box. Lyrics can be in other languages. To get Korean singing, add sung in Korean to the style.

    What does the cleaned version change?

    It removes duplicate keywords, takes out [tags] and time stamps, and splits off the avoid: part. It does not change the meaning.
