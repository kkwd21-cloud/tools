1단계 · 곡 목록 만들기

올릴 곡을 순서대로 넣어요. 파일을 넣으면 이름과 길이를 읽어 와요. 파일은 어디로도 보내지 않아요.

곡 파일을 여기로 끌어다 놓거나 버튼을 눌러요. (mp3, wav, m4a 등)

아직 곡이 없어요. 파일을 넣거나 직접 입력으로 추가하세요.

곡 사이 처리

합쳐서 올릴 때 곡 사이에 쉬는 시간이나 겹치는 구간을 넣었다면 여기에 같은 값을 넣어요. 시간표가 맞아요.

여러 곡을 하나의 파일로 합쳐야 한다면 합치기 도구를 먼저 쓰세요. 곡 목록은 이 단계에서 이어서 만들면 돼요.

올리기 전에 알아 두면 좋은 것

    
  • 제목은 앞쪽이 중요해요
    검색 결과와 휴대폰에서는 제목 앞부분만 보여요. 핵심 말을 앞에 두세요.
  • 해시태그는 3개만
    앞의 3개만 제목 위에 보이고, 너무 많으면 무시될 수 있어요. 장르, 주제, 종류 정도면 충분해요.
  • 시간표는 곡 이름을 짧게
    챕터 이름이 길면 잘려 보여요. 곡 이름은 짧게 다듬으세요.
  • 썸네일은 문구를 짧게
    작은 화면에서도 읽혀야 해요. 한 줄에 열 글자 안팎이 좋아요.

  


  

    
자주 묻는 질문

    
정말 무료인가요? 파일이 올라가나요?
무료이고 가입이 필요 없어요. 곡 파일은 서버로 보내지 않고 이 브라우저에서 이름과 길이만 읽어요.
유튜브 챕터는 어떻게 만들어지나요?
설명란에 "0:00 곡 이름" 형태의 시간표를 넣으면 돼요. 처음이 0:00이고 3개 이상, 각 구간이 10초 이상이어야 만들어져요.
곡을 합쳐서 올릴 건데 시간이 맞을까요?
합칠 때 곡 사이에 빈 시간이나 겹침을 넣었다면 프로 모드에서 같은 값을 넣어요. 그러면 시간표가 맞아요. 합치기 도구의 시간표와 비교해 봐도 좋아요.
"AI로 만든 음악" 문구는 꼭 넣어야 하나요?
필수라고 단정할 수는 없어서 선택으로 두었어요. 유튜브 스튜디오에 변경되거나 합성된 콘텐츠를 묻는 항목이 있으니, 올릴 때 직접 확인해서 답하세요.
만든 내용이 저장되나요?
진행 중인 내용은 이 브라우저에 임시로 저장돼서 새로고침해도 이어서 할 수 있어요. 곡 파일 자체는 저장하지 않고 이름과 길이만 남겨요.
