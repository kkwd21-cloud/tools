Tips

  • Press ▶ before you cut

    After typing start and end times, press ▶ to hear just that part. Adjust until it sounds right.

  • Fade out an abrupt ending

    Set "Fade out at the very end" to 2–3 seconds in advanced settings for a natural finish.

  • Smooth changes between songs

    Set "Crossfade" to 2–4 seconds so songs overlap as they change. It suits playlists.

  • When songs differ in loudness

    Turn on "Make the songs about the same loudness" so one song is not much louder than the rest.

  • Long audio works best on a computer

    Many or long songs use a lot of memory. A computer is better than a phone.

  • Your originals stay untouched

    This tool only makes a new file, so the original files are not changed.

Questions

Is this MP3 joiner and cutter free?

Yes. It is free, needs no sign-up, and everything happens in your browser.

Is my audio uploaded to a server?

No. This site is a static page with no server, so your files are never sent anywhere. They are processed only on your own computer or phone.

Does the sound quality get worse?

Saving as MP3 compresses the audio once more, so there can be a very small difference. The default is 192 kbps. Choose 320 kbps or save as WAV if you need higher quality.

Which files can I use?

Any file your browser can play, such as mp3, wav, m4a, ogg or flac. You can save as MP3 or WAV.

How many songs can I join?

There is no fixed limit. Songs are processed one at a time and then released, so many songs stay fairly light. Very many songs will take time.

Can I cut just one song?

Yes. Add one song, set the start and end times, and save to get a file with only that part.

Can I get the start time of each song in the joined file?

Yes. When joining finishes, a start-time list is made. You can paste it straight into a YouTube description.

Does it work on a phone?

A few short songs should work, but long or many songs can run out of memory. A computer is recommended.
