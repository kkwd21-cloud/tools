Tips for good timing

  • Slow listening helps

    Turn on "Listen slowly" so you do not miss the moment a line starts. Saved times are computed for normal speed.

  • Pressing a little late is fine

    People always press a bit late. "Press-time correction" in advanced settings (0.15 sec by default) moves it earlier by that much.

  • Only fix the lines that are off

    Auto timing already runs when you press Start, so just fix the wrong lines in "Check and fix each line".

  • Undo if you slip

    Press "Undo one line" to go back and press that line again.

  • Press every chorus line too

    Repeated lines still have different times. Pressing line by line keeps it accurate.

  • Fix typos on the spot

    Click the text of a line in the list to edit it. The saved file updates right away.

Questions

Is this lyrics subtitle tool free?

Yes. It is free, needs no sign-up, and everything happens in your browser.

Is my audio uploaded to a server?

No. This site is a static page with no server, so your file is never sent anywhere. It is processed only on your own computer or phone.

Does it work without pressing the button?

It makes a rough automatic guess when you press Start, but it is not exact. Pressing the button as each line starts makes it accurate.

Which audio files work?

Any file your browser can play, such as mp3, wav, m4a or ogg. A very long file may run out of memory during waveform analysis. You can still press the button as you listen.

What happens to Suno tags like [Verse]?

By default tag lines are skipped and the time is split between the lyric lines. Turn the option off to treat tags as lines.

What is the difference between the lyrics file (LRC) and the subtitle file (SRT)?

The lyrics file (LRC) has only the start time of each line, and the subtitle file (SRT) has start and end times. Use the lyrics file for video programs and the subtitle file for YouTube captions.

How do I use it in MusicCanvas?

Load the lyrics file (.lrc) from the lyrics menu. The lyrics then appear in your video in time.

What if I lose my work?

The lyrics text is saved automatically in this browser. Timing is not saved, so save the file when you finish.
